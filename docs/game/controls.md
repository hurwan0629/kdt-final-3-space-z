# 조작과 게임 흐름

메인 메뉴는 난이도 선택·무한 스테이지·게임 나가기 버튼으로 구성됩니다. 무한 스테이지로 시작해 WASD로 이동하고 마우스로 조준하며 좌클릭을 유지해 발사합니다. 이동과 조준 방향은 독립적입니다.

확정한 난이도에는 점 표시가 남습니다. 다른 난이도 버튼에 마우스나 키보드 포커스가 있을 때만 확정된 난이도를 조금 투명하게 표시합니다. 무한 스테이지·게임 나가기 또는 확정한 난이도에 포커스가 있으면 확정된 난이도는 선명하게 표시합니다. 버튼 위에 마우스가 있으면 화면의 강조는 마우스 위치를 우선하며, 가리키기만 해서는 난이도가 바뀌지 않습니다.

![플레이](assets/02-playing.png)

좌하단에는 체력·공격력·사거리 및 탄속도·발사속도·이동속도 5종이 고정 표시됩니다. 1–5 또는 해당 + 버튼으로 남은 포인트를 사용합니다. 전직은 좌상단 카드나 F2–F5로 선택합니다. 강화와 전직 선택 중에도 전투는 계속됩니다.

R은 재장전, Tab은 누르고 있는 동안 능력치 표시, ESC/P는 일시정지입니다. 설정 메뉴에서 전체화면·줌·조작 안내·디버그·창 전환 시 자동 일시정지를 변경합니다. Q/Space 액티브는 없습니다. 일시정지 메뉴에서 Q는 종료입니다.

N은 새 8×8 랜덤 블록 지형으로 새 게임을 시작합니다. 파일 맵이나 빈 월드를 순환하지 않습니다. 고정 seed로 실행한 경우 N을 누를 때 seed를 하나 증가시키고, 일반 재시작은 현재 seed를 유지합니다. 새 게임에서는 성장과 포인트가 초기화됩니다. 게임 오버 후 Enter로 다시 시작합니다.
