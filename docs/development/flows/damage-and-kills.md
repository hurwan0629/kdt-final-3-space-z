# 피해와 적 처치

## 시작 조건과 참여 객체

탄환 이동 구간의 명중, 몸체 접촉, 범위 피해에서 시작합니다. `Combat`은 개체 체력과 코어 이벤트를 바꾸고, 플레이어가 점수를 얻으면 `PlayerProgression`에 전달합니다.

관련 상태: [[development/classes/Bullet#공격과 충돌|탄환의 피해·관통]], [[development/classes/Tank#체력 상태|선체 체력]], [[development/classes/Shape#종류와 체력|천체 체력·점수]], [[development/classes/PlayerProgression#점수와 레벨|성장 상태]].

## 탄환 명중과 적 처치

1. `_move_bullets()`가 벽까지 이동 가능한 구간을 계산하고 위치·수명을 갱신합니다. 이동 구간에서 `_bullet_hit()`를 호출합니다.
2. `_bullet_hit()`는 살아 있는 상대 진영과 천체를 확인합니다. 이미 맞힌 번호는 제외하고, 먼저 닿는 대상 하나를 고릅니다.
3. 선체는 `_damage_tank()`, 천체는 `_damage_shape()`로 피해를 전달합니다. 범위 피해가 있으면 `_explode()`를 사용합니다.
4. 선체 피해는 종류별 받는 피해 배율을 적용하고 남은 체력만큼만 차감합니다. `last_hit_frame`과 피격·공격 이벤트를 기록합니다.
5. 적 체력이 0 이하가 되면 `alive=False`와 `respawn_timer`를 설정합니다. 플레이어가 처치했다면 `record_kill()`로 처치 수를 늘립니다. 엘리트라면 플레이어 회복·알림도 처리합니다.
6. `GameCore.record_score_award()`로 발생 프레임·위치·점수·대상 종류를 기록하고 `_add_score()`에 실제 점수를 전달합니다. 성장 활성화 시 경험치·레벨·강화·진화 대기가 갱신됩니다. 실제 강화 선택을 자동으로 하지는 않습니다.
7. 탄환에 관통이 남으면 횟수를 줄이고 맞힌 번호를 기록합니다. 그 외에는 명중한 탄환을 소멸시킵니다.

## 플레이어 사망과 천체 파괴의 차이

플레이어에게 피해를 주는 `_damage_tank()`는 체력과 피격 이벤트를 바꾼 뒤 반환합니다. 사망 상태는 **같은 코어 프레임 마지막**에 확정합니다. 프레임 증가·재장전 완료 처리 뒤 체력이 여전히 0 이하라면 체력 0·`alive=False`·예약 점사 취소·`game_over=True`·사망 이벤트를 설정합니다.

천체는 플레이어가 준 피해를 점수/최대 체력으로 가중해 이벤트에 기록합니다. 파괴 시 천체 점수와 파괴 수를 누적하고 성장에 전달합니다. 전투 정리에서 목록을 제거한 뒤 코어가 부족한 수를 보충합니다.

## 바뀌는 상태와 소비자

| 보관 객체 | 변경 결과 | 읽는 곳 |
|---|---|---|
| `Tank`·`Shape` | 체력·생존·피격 프레임·재등장 대기 | 코어·적 AI·렌더러·관찰 |
| `GameCore` | 전투 이벤트·점수 획득 기록, 마지막 플레이어 사망 시 종료 상태 | `TankEnv` 또는 사람 플레이의 이벤트 소비 |
| `PlayerProgression` | 처치·점수·경험치·레벨·미사용 보상 | HUD·입력·무기 숙련·적 갱신 |
| `Combat` | 관통·유지할 탄환 목록 | 렌더러와 다음 프레임 |
| `Renderer` | 점수 팝업·불꽃·경험치 반짝임 | 화면 출력 |

`pop_events()`는 누적 이벤트를 꺼내고 새 빈 버퍼로 교체합니다. 학습 환경은 이를 보상으로 계산하고 사람 플레이는 소비해 버퍼가 쌓이지 않게 합니다. 게임 점수와 학습 보상은 서로 다른 값입니다.

점수 획득 기록은 별도의 `pop_score_award_events()`로 꺼냅니다. 앱은 매 코어 프레임 전달하고, 학습 화면은 환경의 `render()`에서 모아 전달합니다. 화면 없는 환경은 버립니다. `Renderer.add_score_popups()`가 이 사실을 화면 상태로 변환해 표시·만료를 관리합니다. 자세한 상태는 [[development/classes/Renderer#점수 팝업|점수 팝업]]에 있습니다.

## 예시

받는 피해 배율이 1이고 체력이 20인 적에게 피해 7을 세 번 주면 7 → 7 → 6만큼 실제 피해가 기록됩니다. 마지막 타격에서 적 처치는 한 번만 기록합니다. 이미 체력이 0인 적을 다시 피해 함수에 전달해도 양수 피해가 없어 처치 점수를 다시 지급하지 않습니다.
