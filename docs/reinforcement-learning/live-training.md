# Space Z 실시간 강화학습

## 실행

`C:\wooki\game`의 `강화학습_시작.pyw`를 더블클릭합니다. 별도 학습 환경에서 PPO 학습과 모니터 창이 열립니다. `강화학습_이어하기.pyw`는 마지막 실행의 체크포인트와 관찰 정규화 통계, 최적화 상태를 복원합니다. `강화학습_화면보기.pyw`는 기존 실행을 보기만 하므로 창을 닫아도 학습을 중지하지 않습니다.

일반 실행 창의 **저장 후 종료 / Esc / 창 닫기**는 학습에 중지 요청을 보내고 마지막 모델을 저장합니다. 일시정지 버튼 또는 **P**로 학습을 멈추거나 재개합니다. **D**는 시연 정책의 결정론/탐색 선택, **+/-**는 시연 속도입니다. 시연 속도를 바꿔도 실제 학습 예산이나 속도를 바꾸지 않습니다.

첫 실행은 원래 난이도에서 무작위 기준선을 측정하므로 잠시 `무작위 기준선 평가`가 표시됩니다. 학습은 기본 총 2,000,000 환경 step이며 PC 속도에 따라 오래 걸릴 수 있습니다. 창에 측정된 처리량과 남은 예상 시간이 표시됩니다. 기준선/평가 시간도 경과 시간에 포함하므로 예상 시간은 평가 직후 달라질 수 있습니다.

## 선택한 모델

주 모델은 **PPO + 4시점 관찰 기록 + 벡터/벽 격자 인코더**입니다. 이 게임은 적·탄환의 이동과 장애물 대응을 함께 배워야 하므로 최근 관찰 기록과 국소 벽 정보를 따로 처리합니다. 27개 이산 행동에 대한 정책과 가치 함수를 함께 학습하며, 네트워크는 작은 규모로 구성해 CPU 환경 병렬 실행에 맞췄습니다. 이 설계가 모든 다른 모델보다 좋다는 보장은 없으며, 실제 평가로 모델을 선택합니다.

기존 게임 실행과 `TankEnv()`의 241차원 기본 관찰은 변경하지 않습니다. 새 학습 모드는 706차원(벡터 265 + 벽 441), 최근 4시점 기록을 사용합니다. 벡터: 플레이어, 적 9대, 천체 12개, 적 탄환 16개, 벽 거리 센서 16개, 가까운 적/천체의 상대 방향·시야 여부·체력, 경과 시간. 격자는 21×21입니다. 적 위치 센서는 기존 환경처럼 화면의 가시 범위 밖 정보도 포함하므로, 순수 픽셀 기반 에이전트와의 비교에는 주의합니다. 직접 조준하거나 대신 이동하는 규칙은 넣지 않았으며 행동은 모델이 선택합니다.

PPO: γ=.995, GAE=.95, clip=.15, rollout512×4환경, batch256, 6 epochs, gradient norm=.5, target KL=.025. 학습률은 3e-4에서 5e-5까지, entropy 계수는 .02에서 .004까지 줄입니다. Actor/Critic 각각 128×128 MLP, 별도 벡터 MLP와 작은 CNN을 사용합니다. GPU가 있어도 이 설치는 CPU용 PyTorch를 사용하며, GPU 대비 우월성을 측정했다는 뜻은 아닙니다.

## 보상

| 항목 | 보상 |
|---|---:|
| 적에게 준 피해 | 피해량 × .02 |
| 적 처치 | 1대당 +6 |
| 천체 파괴 | 1개당 +.15 |
| 천체 피해 | 기존 가중 피해 / 최대 천체 점수 × .1 |
| 받은 피해 | 피해량 × -.03 |
| 사망 | -6 |
| 조준·접근 보조 | .995 × 다음 potential - 이전 potential |
| 이동 명령을 내렸지만 장시간 막힘 | 해당 step -.002 |

단순 생존 시간이나 이동 거리만으로 점수를 주지 않습니다. 천체의 큰 게임 점수는 학습 보상에 직접 넣지 않아 천체 파괴가 적 전투보다 과도하게 유리해지는 문제를 줄였습니다. Potential은 가까운 대상과의 거리·조준 방향으로 계산한 작은 값이며 사망 시에만 다음 potential을 0으로 둡니다. 시간 제한 종료에는 가치 부트스트랩을 유지합니다. 막힘 보상은 과제 목적을 조금 바꾸는 보조 항목이므로, 보상 구성별 효과는 실험으로 확인해야 합니다.

## 난이도와 평가

- 0~100,000 step: 작은 열린 경기장, 적 3대, 완화한 조준/이동.
- 100,000~350,000 step: 원래 크기의 장애물 맵, 적 6대.
- 350,000 step 이후: 원래 설정의 적 9대.

난이도는 에피소드가 새로 시작할 때 바뀝니다. 학습 보상은 서로 다른 난이도 사이에서 직접 성능 순위를 뜻하지 않습니다. 별도 평가는 **항상 원래 난이도**, 고정 평가 seed(900001~), 1500 step 제한으로 진행합니다. 학습 에피소드 제한은 3000 step입니다. 고정 평가 seed는 체크포인트 선택에 사용되는 검증 집합이며, 최종 보고에는 학습/검증에 쓰지 않은 추가 시험 seed를 권장합니다. 평가의 평균·표준편차, 처치·생존 시간과 비용을 함께 보세요.

관찰 정규화 통계는 학습에서만 갱신하고 평가/시연에서는 고정합니다. 최고 모델은 보조 보상을 제외한 **기본 과제 보상**의 평가 평균으로 선택합니다. 학습 보상·게임 점수·기본 과제 보상을 구분해 기록합니다.

## 화면과 파일

화면 왼쪽은 **가장 최근 저장한 정책의 별도 시연**입니다. 실제 학습 worker의 동일한 프레임을 중계하는 것은 아닙니다. 오른쪽/아래의 step, 업데이트, 손실, KL, 평가 그래프는 학습 프로세스가 직접 기록한 값입니다. 정책은 체크포인트 갱신 시 다시 불러오므로 학습 worker보다 조금 늦게 반영됩니다. CPU로 실행하는 작은 정책이며, 렌더링은 별도 프로세스여서 그림을 그리는 속도가 학습의 목표 FPS가 되지 않습니다.

실행별 폴더: 프로젝트의 `runs/ppo-날짜-시각/`.

- `status.json`: 현재 상태와 최근 그래프 데이터
- `episodes.csv`: 학습 에피소드의 보상·피해·처치·생존·난이도·시드
- `evaluations.csv`, `random_baseline.json`: 고정 난이도 검증과 무작위 기준선
- `latest.json`, `best.json`: 모델과 관찰 통계가 같은 세대에 속하는 체크포인트 경로
- `trainer.log`: 실행 로그 / 오류
- `config.json`: 재현에 필요한 설정

체크포인트는 `checkpoints/<step>-<id>/`에 모델과 관찰 통계를 함께 저장한 뒤 경로를 교체합니다. 최근 세대와 최고 세대를 보관합니다. DQN replay buffer는 정상 중지/완료 시 저장하며, 비정상 종료 후에는 최근 경험 일부가 없을 수 있습니다.

## 명령줄과 DQN 비교

프로젝트 폴더에서 전용 Python을 사용합니다.

```powershell
$env:PYTHONPATH = "$PWD\src"
..\.venv-rl\Scripts\python.exe -m space_z.rl.training_wooki.launch
..\.venv-rl\Scripts\python.exe -m space_z.rl.training_wooki.launch --resume
..\.venv-rl\Scripts\python.exe -m space_z.rl.training_wooki.launch --algorithm dqn --no-curriculum
..\.venv-rl\Scripts\python.exe -m space_z.rl.training_wooki.launch --algorithm ppo --no-curriculum
..\.venv-rl\Scripts\python.exe -m space_z.rl.training_wooki.launch --run-dir runs\실행폴더 --watch
```

DQN은 같은 관찰/보상을 사용하며 replay20,000, warmup3000, batch128, train frequency4, target update2000, ε 탐색을 사용합니다. DQN/PPO 발표 비교에서는 curriculum 사용 여부, 총 환경 step, 평가 seed와 horizon, 장비를 맞추고 알고리즘별 병렬 환경 수 및 소요 시간을 함께 공개합니다. 현재 기본 성능 향상은 실험 전 가설이며, smoke test 통과는 학습 성능 보장이 아닙니다.

설계 참고: [PPO 공식 문서](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html), [강화학습 실험 지침](https://stable-baselines3.readthedocs.io/en/master/guide/rl_tips.html).
