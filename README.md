# Space Z

Python/Pygame 기반 탑뷰 우주선 슈팅 게임과 화면 없는 강화학습 환경입니다.

## 실행과 검증

```powershell
python -m pip install -e .
python -m space_z
python -m space_z --seed 42 --map belt
python -m space_z --random-map
python -m space_z --stage2
python -m space_z --no-terrain
python -m space_z --limited-ammo   # 기본은 탄약 무제한, 이 플래그로 120발 제한 켜기
python -m unittest discover -s tests -v
python scripts/random_agent_test.py
```

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동, 대각선 이동 가능 |
| 마우스 / 좌클릭 | 조준 / 주무기 발사 |
| 1–5 / 좌하단 + | 체력·공격력·사거리 및 탄속도·발사속도·이동속도 강화 |
| F2–F5 / 전직 카드 클릭 | 표시된 진화 선택 |
| Tab 유지 | 현재 능력치 보기 |
| R | 재장전 (기본 실행은 탄약 무제한이라 필요 없음; `--limited-ammo`로 켜면 120발 / 2.5초) |
| ESC / P | 일시정지 설정 메뉴 |
| N | 새 8×8 랜덤 블록 지형으로 새 게임 |
| Enter | 게임 오버 후 새 게임 |
| F1 | 디버그 표시 |

Q·Space 액티브 스킬은 제거했습니다. 설정 메뉴의 Q 종료 단축키는 유지합니다.

## 스탯과 성장

좌하단에는 다음 5종이 고정 순서로 항상 표시됩니다. 포인트가 없으면 강화할 수 없으며 발사속도 한계에 도달한 행은 MAX로 표시합니다.

| 번호 | 스탯 | 1포인트 효과 |
|---|---|---|
| 1 | 체력 | 최대 체력 +25, 현재 체력 +25(최대치 제한) |
| 2 | 공격력 | 주무기 피해 ×1.25 |
| 3 | 사거리 및 탄속도 | 탄속 ×1.2, 탄환 수명 ×1.15 |
| 4 | 발사속도 | 기본 발사 대기 ×0.95 후 반올림, 최소 4프레임 |
| 5 | 이동속도 | 이동 가속도 ×1.07 |

점수만큼 경험치를 얻고 다음 레벨의 요구량은 `60 + (현재 레벨 - 1) × 40`입니다. 일반 레벨업마다 강화 포인트 1개를 주며, 쓰지 않은 포인트는 계속 누적하고 화면에 표시합니다. 10의 배수 레벨은 별도의 전직·숙련 보상을 줍니다. 전직을 미뤄도 순서대로 선택할 수 있고 일반 강화와 남은 포인트는 유지됩니다. 새 게임·맵 변경 시 초기화합니다.

## 우주선 진화: 21종

모든 플레이어 우주선은 제공된 512×512 투명 PNG를 사용하며 원본은 오른쪽(0도)을 향합니다. 실제 파일명의 공백도 `ShipClass.asset`에 반영했습니다.

```text
베이직
├─ Lv10 트윈
│  ├─ Lv20 듀얼 스트라이커 → Lv30 개틀링 스톰
│  └─ Lv20 트리플 윙 → Lv30 펜타 윙
├─ Lv10 스나이퍼
│  ├─ Lv20 레일거너 → Lv30 하이퍼 레일건
│  └─ Lv20 헌터 → Lv30 프레데터
├─ Lv10 플랭크
│  ├─ Lv20 쿼드 윙 → Lv30 옥타 스타
│  └─ Lv20 트윈 플랭크 → Lv30 헥사 크루저
└─ Lv10 가디언
   ├─ Lv20 바스티온 → Lv30 콜로서스
   └─ Lv20 이지스 → Lv30 시타델
```

트윈 계열은 교차 연사·순차 4/6연사 또는 3/5방향 동시 탄막, 스나이퍼 계열은 모두 한 번에 일반 저격탄 1발을 발사하며 단계별 피해·탄속·사거리로 차별화합니다. 헌터·프레데터도 단발입니다. 플랭크 계열은 전후방·사방·8방향 또는 전후 쌍포와 측면포를 사용합니다. 가디언 계열은 큰 선체·높은 체력·피해 감소와 약한 소형 견제포를 갖습니다. 최종 진화는 직전 기체의 직계 자식 하나로 연결되고, Lv40부터 매 10레벨은 현재 기체 숙련 보상입니다.

`python -m space_z` 기본 실행은 탄약 무제한입니다(`--limited-ammo`로 켜거나, `GameConfig(limited_ammo=True)`로 직접 설정 가능). 켜면 탄환마다 탄약 1발을 쓰고, 순차 발사는 실제 탄환이 나오는 시점에 소모하며, 재장전·사망·전직 시 남은 연사 묶음은 취소됩니다. 탄환은 처음 맞은 대상에 피해를 주고 사라지며 벽에서 멈추는데, 스나이퍼 계열(스나이퍼/레일거너/헌터/하이퍼 레일건/프레데터)은 관통 1회가 있어 대상 하나를 더 맞힙니다.

## 기체 크기와 전체 미니맵

플레이어와 적 우주선은 이전보다 가로·세로가 각각 2배이고 실제 충돌 반경도 2배입니다. 기본 선체 반경은 44px, 가장 큰 시타델은 96px입니다. 탄환 충돌 크기는 포신 입구를 기준으로 계산하고, 작은 탄환의 표시는 화면 기준 최소 4px로 보정합니다.

오른쪽 아래에는 카메라·줌과 무관한 전체 미니맵이 표시됩니다. 밝은 회색 공간에 진한 회색 벽을 그리고 플레이어 위치와 방향만 표시합니다. 적 위치는 표시하지 않습니다.

## 맵

48px 타일의 134×101 전체 월드(6432×4848)를 사용합니다. 이전 4800×3600 대비 면적 약 1.8배이며 적은 9대입니다. **맵을 지정하지 않으면 매판 새 랜덤 블록 지형**을 만듭니다. 통로와 벽 블록은 기본 8칸(384px)이며, 외곽 벽띠만 제거하고 내부 장애물은 유지합니다. 카메라는 가장자리에서도 플레이어를 중앙에 두고 맵 밖에는 우주 배경을 표시하며, 선체는 월드 경계까지 이동할 수 있습니다. 저장된 네 맵은 원본을 검증한 뒤 현재 월드 크기에 맞춰 고정 시드로 생성합니다.

| 문자 | 지형 |
|---|---|
| `.` | 빈 공간 |
| `#` | 이동·탄환·시야를 막는 벽 |
| `~` | stage2에서 감속시키는 중력장 |
| `+` | stage2에서 파괴 가능한 벽, 기본은 일반 벽 |
| `P`, `E` | 플레이어·적 시작 위치 |

`drift`, `ring`, `belt`, `hello-world` 맵을 사용할 수 있습니다. 랜덤 맵도 큰 벽과 통로의 연결성을 검사합니다.

## 파일 구조

실행 코드는 `src/space_z/`에 있습니다. `config/`는 설정·정의, `game/`은 공통 규칙, `rendering/`은 화면, `rl/`은 학습 환경입니다. `main.py`는 실행 준비, `app.py`는 입력·메뉴를 관리합니다.

`assets/`, `maps/`, `tests/`, `docs/`는 프로젝트 루트에 유지합니다. 검증·문서 생성 도구는 `scripts/`에 있습니다. [폴더와 객체의 상세 지도](docs/development/project-structure.md)를 참고하세요.

## 강화학습

`python -m pip install -e ".[rl]"`로 선택 의존성을 설치합니다. 환경에 관찰 생성기·행동 해석기·보상 계산기를 전달하며 게임 설정의 성장 여부를 그대로 사용합니다.

```python
from space_z.config import GameConfig, RewardConfig
from space_z.rl import TankEnv, VectorObservation, DiscreteActionDecoder, RewardCalculator

env = TankEnv(
    GameConfig(),
    VectorObservation(),
    DiscreteActionDecoder(enable_stat_upgrades=True, enable_evolution=True),
    RewardCalculator(RewardConfig()),
)
try:
    observation, info = env.reset(seed=42)
    observation, reward, terminated, truncated, info = env.step(0)
finally:
    env.close()
```

기본 벡터는 45×29타일 범위의 5139차원이며, 픽셀 관찰은 이미지 4장과 성장 벡터를 반환합니다. 이산·연속 행동을 교체할 수 있고 발사·스탯 강화·전직 요청을 지원합니다. 같은 seed·행동·성장 선택으로 결과를 재현합니다. 평가·자원 측정도 제공하며 `train.py`는 아직 구현하지 않았습니다. [상세 사용법과 반환 형식](docs/reinforcement-learning/environment.md)을 참고하세요.

## 실행 파일 만들기


설치·게임 안내·클래스·동작 흐름은 [문서 목차](docs/README.md)에서 찾아볼 수 있습니다.

## 중앙 카메라와 확장 월드

기본 월드는 134×101 타일, 6432×4848px로 이전 4800×3600px 대비 면적 약 1.8배입니다. 적은 6대에서 9대로 늘었습니다. 카메라는 맵 가장자리에서도 플레이어를 항상 화면 중앙에 두며, 맵 밖에는 우주 배경이 보입니다. 우주선은 월드 경계까지 이동할 수 있습니다. 생성된 맵의 외곽 벽띠는 제거하고 내부 장애물은 유지합니다. 미니맵 위 클릭도 일반 사격으로 처리합니다. 무제한 탄약 모드의 우상단 탄약 패널은 표시하지 않고, ESC 메뉴 안내는 중앙 상단 Tab 능력치 옆에 표시합니다.

진화 트리 이미지는 현재 21종 정의와 일치합니다. Lv10·20·30에 카드를 선택하면 진화하며, 적은 선택 완료한 플레이어 기체 단계에 맞춰 진화합니다.
