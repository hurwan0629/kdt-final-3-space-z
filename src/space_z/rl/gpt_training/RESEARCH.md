# 점수 개선 실험

015 이후의 추가 개선·현재 공개 모델은 [RESEARCH_PHASE2.md](RESEARCH_PHASE2.md)에 기록한다.

## 목표와 비교 기준

- 모방학습 없이 PPO만 사용한다. 입력은 공유 VectorObservation의 5,139개 숫자를 그대로 유지한다.
- 이동·회전·발사·강화·진화의 선택은 정책이 한다. 불가능한 성장 요청만 관찰의 가능 여부로 제외한다.
- 실제 기본 GameConfig에서 게임 점수 증가가 목표다. 연습 환경 보상 증가를 성공으로 대신하지 않는다.
- 이전 순수 PPO 비교 모델: `experiments/005_pure_ppo_full/checkpoints/best.zip` (132,608 step).
- 고정 검증: 시드 101·202·303·404·505·606, 최대 3,000 환경 step = 200초.
- 후보 선택 순서: 평균 게임 점수 → 평균 생존 → 제한 시간 도달 비율.
- 마지막 독립 테스트: 시드 7001·7102·7203·7304·7405·7506·7607·7708·7809·7910,
  최대 6,000 step = 400초. 후보를 확정한 뒤 비교 모델과 같은 조건으로 평가한다.
- 200초 검증의 평균 점수 1,000점을 첫 실용 목표로 삼되, 독립 테스트의 점수·중앙값·시드별 승패도 확인한다.
- 소스·출력·의존성은 gpt_training 안에 둔다. Windows 실행기까지 포함해 총 8개 이하가 되도록 작업 환경은 최대 6개다.

## 원인 가설

1. 이전 큰 MLP는 개체와 지형의 구조를 한꺼번에 처리했다. 개체별 공유 인코더와 지형 CNN으로 분리한다.
2. 상대 위치와 포신 방향의 관계를 찾는 부담이 크다. 신경망 안에서 관찰 좌표를 포신 기준 좌표로 변환한다.
   관찰 정보만 재표현하며 교사 행동·추천 행동·정답 라벨은 사용하지 않는다.
3. 이전 적 없는 연습은 표적이 멀고 보상의 상당 부분이 고정 생존 보너스였다.
   작은 연습 맵에서 실제 명중 빈도를 높이고, 고정 생존 보너스를 제거한다.
4. 조준·접근 진전 보상은 potential의 차이 `gamma * phi(next) - phi(previous)`로 계산한다.
   사망 상태 potential은 0으로 한다. 이 보조 항과 실제 점수·피해 보상을 따로 기록한다.

## 기록 방식

각 실험의 `experiment.json`에 목표·가설·게임 설정·보상 계수·PPO 설정·부모 모델 해시·소스 사본 해시를 보관한다.
`episodes.jsonl`에는 보상 항목별 누적값과 점수·처치·생존을 기록한다.
`evaluations.jsonl`과 TensorBoard에는 일정 학습량마다 동일 기본 게임에서 측정한 결과를 남긴다.
성능이 나빠진 체크포인트도 보존하고 다음 실험의 선택 이유를 이 문서에 추가한다.

참고: [SB3 사용자 특징 추출기](https://stable-baselines3.readthedocs.io/en/master/guide/custom_policy.html),
[potential 기반 보상 변환 원 논문](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf).
유한 관찰·근사 신경망·유한 학습에서는 보조 보상의 이론만으로 성능 개선을 보장할 수 없으므로 실제 게임 점수로 확인한다.

## 008: 기본 게임 직접 학습과 발사·위험 보상

- 이름: `008_full_score_v3`. 부모는 006 best, 135,168 step. 007의 악화된 마지막 가중치는 쓰지 않는다.
- 가설: 쉬운 환경에 치우친 전이를 줄이기 위해 처음부터 기본 게임의 벽·적 9기·적 발사를 경험하게 한다.
  명중의 지연 신호를 보완하고, 실제 생존 위험에 대한 비용을 강화한다.
- 환경·관찰·행동·신경망은 기본 게임 및 기존 5,139개 입력을 유지한다.
- 보상 `score_v3`: 적 피해 계수 0.015→0.05, 체력 비율 피격 계수 0.5→2,
  사망 비용 2→3. 기존 점수·천체 피해·potential 진전 보상은 유지한다.
- 실제 발사가 있었고 사거리·시야선 안의 표적을 조준한 경우 최대 0.15의 즉시 보조 보상.
  표적 속도를 사용해 짧은 예상 이동을 반영하며, 산탄 수에 따라 보상이 부풀지 않게 step당 상한을 둔다.
- 관찰된 적 탄환의 직선 궤도로 근접 위험을 계산해 최대 0.02/step의 비용을 준다.
  이 비용과 발사 보너스는 추가 설계 보상이며, 전체 보상이 점수만 최적화한다고 주장하지 않는다.
- 정답 행동을 만들거나 모방 손실로 학습하지 않는다. 모든 조작·가중치는 PPO가 보상으로 학습한다.
- 요청 최대 524,288 추가 step, 검증 간격 65,536. 중간 검증을 보고 계속할지 판단한다.
  중단이 필요하면 `stop.request`에 이유를 적어 검증 경계에서 모델·상태를 저장하고 종료한다.

## 010: 정지 사격장에서 PPO 조준 기술 분리 학습

- 이름: `010_stationary_range`. 부모는 009 best, 202,752 step이다.
- 가설: 이동·피격·조준이 동시에 변하는 어려운 과제 대신, 기존 제어 신경망을 보존하고
  추가 조준 신경망에만 PPO 행동 경사를 주면 회전·발사의 정밀도가 더 빨리 학습된다.
- 연습에서만 이동 요청을 적용하지 않는다. 플레이어 물리·관찰 정규화 설정은 그대로 둔다.
- 적·내부 벽 없이 정지 천체 하나를 거리 220–480, 무작위 각도에 생성한다. 천체 최대 체력을 7로 낮춰
  초기 기본 무기로 명중 시 즉시 파괴되는 연습을 만든다. 파괴 후 실제 엔진의 새 천체를 다시 배치한다.
  점수는 실제 명중·파괴 이벤트로만 얻으며 직접 더하지 않는다.
- 기존 인코더·actor MLP·기존 행동 head는 동결한다. PPO의 critic MLP와 조준 잔차 신경망을 학습한다.
  기존 이동·성장 정책을 덮어쓰지 않는다. 이후 기본 게임 학습에서는 동결을 해제할 수 있다.
- `score_v5`: v4와 같고 potential 크기만 0.8→0.2로 줄여 작은 천체 파괴 시 보조 보상의 감소가
  실제 파괴 보상을 압도하지 않게 한다. 모든 변경은 연습 조건이며 기본 게임 평가에는 적용하지 않는다.
- 입력은 여전히 5,139차원, 모든 새 학습은 PPO이며 시연·정답 행동은 없다.
