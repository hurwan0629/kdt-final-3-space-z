# 실험 기록

## 순수 PPO 전환 — 004부터

사용자 요청에 따라 새 기본 방식은 `pure_ppo`다. 001–003은 이전 혼합 학습 이력으로 보존한다.
시연 수집·모방 학습·교사 평가를 실행하지 않으며, 첫 모델은 무작위 초기화한다.
이후 단계는 순수 PPO 체크포인트만 이어받는다. 이전 혼합 정책의 가중치는 사용하지 않는다.

- 관찰: 기존 `VectorObservation` 5,139개. 추천 이동·조준점 같은 규칙의 출력은 제외한다.
- 행동: 이동 9, 회전 9, 발사 2, 강화 6, 진화 5의 독립 분기. 강화·진화도 정책이 선택한다.
- 보상: 이전의 점수 증가·피해·사망·생존 보상을 유지한다. 교사 행동과의 유사도 보상은 없다.
- 첫 단계 `004_pure_ppo_harvest`: seed 2031, 요청 131,072 PPO step, 적·내부 벽 없는 환경.
- PPO: n_steps 256, batch_size 256, n_epochs 4, learning_rate 0.0003, gamma 0.995,
  entropy coefficient 0.02, clip_range 0.15, target_kl 0.02, actor/critic 각각 [128, 128].
- 평가는 자동 성장이 없는 동일 관찰·행동 형식으로 기본 게임에서 수행한다.
- 고정 검증 시드 101·202·303, 최대 3,000 환경 step(200초)을 사용한다.
- 새로운 독립 시드 1101·1202·1303은 마지막 후보를 정한 뒤 확인한다.
- 실제 공유 디코더와 전체 행동 조합의 일치, 자동 성장 미호출, 정책 성장 요청 적용,
  환경 계약, 실제 PPO 업데이트와 ZIP 복원을 `pure_ppo_checks.log`에 검증했다.

### 004 결과와 다음 단계

- 실제 PPO step: 132,608. 시연 파일·모방 체크포인트는 생성되지 않았다.
- 초기 무학습 정책의 기본 게임 평가: 평균 점수 36.67, 적 처치 0, 생존 55.58초.
- 004 final의 같은 평가: 평균 점수 3.33, 적 처치 0, 생존 60.85초.
- 적 없는 연습만으로는 기본 게임 점수가 개선되지 않았다. 이 부정 결과를 보존한다.
- `005_pure_ppo_full`은 004 final의 순수 PPO 가중치만 이어받아 기본 게임에서 추가 262,144 step을 요청한다.
  에피소드 제한은 3,000 step이며 적 발사·벽·탄속·적 수는 기본값이다.

### 005 결과와 최종 확인

- 추가 PPO 263,424 step, 누적 396,032 step. 004 약 170.30초, 005 약 457.97초 소요.
- 고정 검증에서 005 final은 평균 점수 3.33, 적 처치 0, 생존 43.62초였다.
- 정해 둔 순위 기준에서는 005 시작 시점의 정책이 유지됐다. 이 정책은 무학습 상태가 아니라
  004에서 이미 132,608 step을 순수 PPO로 학습한 체크포인트다.
- 검증 선택은 별도 시드 결과를 보기 전에 끝났다. 이후 시드 1101·1202·1303,
  기본 게임·최대 400초로 세 정책을 순차 평가했다. 이 결과를 보고 재학습하지 않았다.

- 모방 없는 학습 경로와 실행은 완료했지만 **안정적인 조준·장기 생존·고득점은 달성하지 못했다.**
  낮은 결과를 성공으로 해석하지 않는다. 세 시드·한 학습 초기화로 통계적 우위도 주장하지 않는다.

- 시연 입력을 요청하면 실행 폴더 생성 전에 거부하는 것도 확인했다. 실제 학습 실행에는
  `demonstrations.npz`·`imitation.zip`·teacher 평가가 없다.
- 순수 PPO 기본 재생 경로에서 실제 체크포인트 로드·SDL dummy 5 step 렌더링을 확인했다.
  실제 창의 시각적 검수는 하지 않았다. 공유 소스·맵 47개 해시는 변경되지 않았다.

아래 001–003의 성능은 모방학습을 포함한 과거 결과이며 순수 PPO의 성과로 해석하지 않는다.

## 범위와 성공 기준

- 이 폴더만 변경한다. 공유 게임 규칙과 기존 학습 결과는 보존한다.
- 작업 프로세스 7개 + 조정 프로세스 1개 이하로 실행한다.
- 높은 학습 보상만으로 성공을 판단하지 않는다. 기본 GameConfig에서 고정 시드의 실제 점수·처치·생존 시간을 비교한다.
- 학습용 환경은 따로 명시하고, 평가 환경에서는 적 발사·기본 탄속·기본 지형을 유지한다.
- 평가 최대 시간에 도달한 판은 생존 시간의 하한일 뿐이다. 제한 없는 생존이나 게임 숙달을 입증하지 않는다.
- 성장 선택은 고정 규칙, 이동·조준·발사는 학습 정책이다. 규칙 정책과 모방 학습의 기여를 분리해 기록한다.

## 001_imitation_combat

### 가설과 조건

큰 결합 행동 공간에서 처음부터 조준을 발견하도록 하는 대신, 회전을 정밀하게 나누고
현재 상태에서 조준 오차를 계산해 제공하면 짧은 모방 학습으로 유효한 시작 정책을 만들 수 있다.
이후 실제 게임 점수와 생존을 기준으로 PPO를 학습한다.

- 학습: 벽 없는 맵, 발사하는 적 3기, 천체 40개, 기본 탄속.
- 평가: 수정하지 않은 기본 게임, 시드 101·202·303, 최대 3,000 환경 step(200초).
- 데이터: 교사 정책 16,384 전이, 모방 25 epoch.
- PPO: 추가 32,768 step 요청, rollout 단위 초과 가능.
- 작업 환경 7개, CPU 신경망 스레드 1개.
- 시작 정책 평가: 평균 점수 8.33, 평균 생존 82.27초. 3개 시드만 사용한 예비 결과다.

### 관측 결과

|---|---:|---:|---:|
| 무학습 시작 정책 | 8.33 | 0 | 82.27 |
| 규칙 교사 | 2313.33 | 7.67 | 135.29 |
| 모방 학습 직후 | 3070.00 | 9.00 | 200.00 |

- 세 시드 모두 200초 제한까지 생존한 것은 모방 정책이다. PPO 보정은 이 평가에서는 개선되지 않았다.
- 단순화한 combat에서 추가 학습한 것이 기본 게임으로의 일반화를 개선한다는 가설은 지지되지 않았다.
- 다음 실험은 모방 체크포인트에서 다시 시작해 기본 게임에서 PPO를 실행한다. 이미 낮아진 final을 무조건 이어 쓰지 않는다.
- 단일 초기화·평가 시드 3개만 사용했다. 우연과 시드 선택 효과를 배제할 수 없다.
- 원본 데이터: `experiments/001_imitation_combat/evaluations.jsonl`.

## 002_full_ppo

- 003의 고정 200초 평가 성과는 개선됐지만, 새 시드에서는 평균 점수·생존이 001보다 낮았다.

- 다음 연구는 새 미관측 시드 묶음, 여러 학습 시드, 위험 상황 데이터 보강을 우선한다. 여기서는 추가 튜닝하지 않았다.

## 실행·검증 완료 기록

- 실제 PPO 학습 3회: 각각 34,048 / 66,304 / 16,640 step. 총 116,992 PPO step.
- 교사 라벨 데이터 16,384 + 24,576 전이를 별도 저장했다.
- 환경 검사: harvest/combat/full의 관찰 범위·행동·시드 재현성·에피소드 기록.
- 실제 Torch/SB3로 정책 ZIP 저장·복원과 출력 일치 검사.
- 기본 재생 진입점으로 체크포인트를 로드하고 SDL dummy 화면에서 5 step 렌더링 확인.
  실제 사람이 보는 창의 시각적 품질 검수는 하지 않았다. 기존 에셋의 libpng 색상 프로필 경고는 그대로 두었다.
- 공유 소스는 수정하지 않았다. 읽기 전용 소스 사본과 파일별 해시를 이 폴더에 기록했다.
- 기본 게임의 적 발사·탄속·적 수·지형·피해 규칙은 평가에서 바꾸지 않았다.
