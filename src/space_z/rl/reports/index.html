같은 게임, 네 가지 관찰·행동·정책 접근

같은 Space Z 게임 코어 위에서 서로 다른 관찰 구성·행동 공간·정책 구조로 진행한 네 계열의 실험입니다. 각 타일을 선택하면 해당 계열의 실험 계보(변수 변경·분포·held-out 검증)를 처음부터 끝까지 볼 수 있습니다.

교차어텐션 · 완전 연속·이산 혼합

벡터 교차어텐션 하이브리드

개체별 인코더 + 지형 CNN + 개체 간 교차어텐션으로 특징을 뽑고, 이동·회전은 연속, 발사·강화·진화는 이산으로 섞은 22차원 행동을 한 분포에서 학습합니다.

신경망 구조
관찰 벡터(개체·성장·지형) 전용, 이미지 없음
행동 9이동+1회전(연속) + 1발사+6강화+5진화(이산) = 22
정책 교차어텐션 특징 추출 + 공유 PPO
004 best → 007(보상만 상향)에서 held-out +59.7%, 이후 008(보상+lr+환경수 결합)은 이를 넘지 못함
실험 001~008 · 8단계
 회전만 연속 · 디코더 버그 수정 사례

회전 연속 하이브리드

원본 5,139차원 벡터 관찰을 그대로 쓰고, 이동·발사·강화·진화는 이산 분포로, 회전만 tanh-Gaussian 연속 분포로 학습합니다. 200만 스텝 학습 후 발견한 디코더 버그를 고치고 재검증한 사례가 포함됩니다.

신경망 구조 — 장면망·독립 조준망 2계통
관찰 원본 벡터 5,139차원, 가공 없음
행동 이동·발사·강화·진화 이산 + 회전 연속(tanh-Gaussian)
정책 순수 PPO, 결합 log-prob + tanh 자코비안
진화 요청 디코더 버그 수정 후 재검증 — held-out 평균 1,508 → 2,902점 (+92.4%)
실험 001~005 · 5단계
 조준 보조 전처리 · 3단계 연구

조준 보조 이산 행동

가까운 적의 상대 위치·속도 등을 정렬한 조준 보조 입력을 신경망에 추가로 넣고, 이동·회전·발사·강화·진화를 모두 이산 분포로 고르는 가장 오래 이어진 계열입니다. 모방학습 혼합 → 순수 PPO → 체크포인트 가중 평균까지 3단계로 진화했습니다.

신경망 구조
관찰 전술 관찰(조준 보조 전처리 포함)
행동 이동9×회전9×발사×강화6×진화5, 전부 이산(MultiDiscrete)
정책 개체·지형 인코더 + 별도 조준 신경망, 순수 PPO
1단계 모방 혼합 → 2단계 순수 PPO → 3단계 체크포인트 가중 평균, 22개 실험에 걸쳐 진행
실험 001~022 · 3단계 22실험
 지형만 CNN · 연속→이산 비교

지형 격자 CNN

관찰 벡터에서 지형 격자 부분만 작은 CNN으로 압축하고 나머지 수치는 그대로 이어붙이는 가장 단순한 구조입니다. 연속 행동 기준선에서 시작해 지형 CNN을 추가하고, 이후 이산 행동으로 바꿔 소행성·전투 커리큘럼을 단계적으로 늘렸습니다.

신경망 구조
관찰 벡터 + 지형 격자(별도 CNN으로 압축 후 concat)
행동 연속 기준선 → 이산 전환 후 비교
정책 TerrainGridFeaturesExtractor + MLP, 순수 PPO
연속→이산 전환, 지형 CNN 추가 효과, 소행성→전투 커리큘럼 확장을 단계별로 비교
run 002~005 · 세부 단계 다수
각 페이지의 수치는 해당 실험 폴더의 experiment.json/config.json, episodes.jsonl, evaluations.jsonl 등 원본 로그에서 직접 뽑은 값입니다. 이 갤러리와 하위 페이지는 자동 재생성되는 리포트가 아니라, 조사 시점의 수치를 담은 프로토타입입니다.
